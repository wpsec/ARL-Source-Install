# 全系统扫描信息悬浮展示统一改造计划

状态：已归档。代码实现、自动化测试、TypeScript 检查和生产构建已完成；真实浏览器与虚拟滚动验收待现场完成。

## Summary

将扫描信息的悬浮查看从“部分字段按文本长度判断”统一为实际布局溢出检测：

- 所有扫描资产、风险和情报表格中的文本字段，只要被截断、折叠、隐藏或显示不完整，都支持鼠标悬停和键盘聚焦查看完整内容。
- 固定列宽继续保留，长文本不得撑开列宽或溢出到相邻列。
- 不再按字符数阈值或列对齐方式排除字段，IP、端口、CNAME、状态附加信息等字段统一处理。
- 保留 Portal、键盘聚焦、复制完整内容、Esc 关闭和现有点击行为。
- `onCopy` 改为可选；没有复制能力的 `DataTable` 单元格仍支持悬浮查看，但不显示复制按钮。
- 不修改后端接口和数据结构。

覆盖模块：

```text
站点、资产站点、子域名、资产域名、IP、资产IP、
SSL证书、服务、NPoC服务、目录扫描、URL信息、
WIH、WIH接口、WAF识别、风险、Nuclei结果
```

同时覆盖 Dashboard、ICP 查询结果/历史/任务/日志、AI 日志等复用 `DataTable` 或自定义表格的文本型单元格。

## Implementation Changes

### 1. `HoverCellValue` 统一检测

- 通过 `scrollWidth > clientWidth` 检测横向截断。
- 通过 `scrollHeight > clientHeight` 检测多行或高度截断。
- 遍历子元素，识别 `truncate`、`max-height`、`overflow-hidden` 造成的实际隐藏。
- 使用 `ResizeObserver` 和首次布局后的测量，适配窗口缩放、列宽变化和虚拟列表重新挂载。
- 增加 `forceHover`，供展开/收起类预览在布局尚未完成时查看原文。
- 空内容或 `-` 不生成悬浮面板。
- 面板继续使用 Portal，并在窗口边界不足时翻转或限制位置；面板内容在小屏幕上可滚动。
- 保留鼠标悬停、键盘聚焦、复制完整原文和 Esc 关闭行为。

### 2. `DataTable` 默认单元格接入

- 默认文本单元格统一使用 `HoverCellValue`。
- 数组值、缺失字段和格式化值继续保留完整预览文本。
- 单元格使用 `min-w-0`、`max-w-full`、`overflow-hidden` 和受控最大高度，避免穿透 `td` 边界。
- 自定义 `render` 单元格由调用方显式接入；AI 日志的模型、用户输入摘要和 AI 回复摘要已完成接入。
- Dashboard 最近任务及 ICP 查询结果、历史、批量任务和日志中的长文本单元格已完成接入。

### 3. `TableModuleView` 全量收口

- 移除文本长度超过 48、ID 长度超过 38、包含换行、非居中列等悬浮判断条件。
- 站点标题、域名记录、IP/端口/CDN 名称、证书摘要、URL/标题/来源等统一使用实际溢出检测。
- 响应头、指纹、WIH 内容、任务目标、任务配置、验证信息和文件路径等主动折叠字段使用 `forceHover` 或受控高度检测。
- ID、URL 和文件路径的省略预览绑定完整原文；居中列、数字列、IP、端口和 CNAME 不再被排除。
- AI 分析、WIH、Nuclei、风险和服务等文本型状态信息统一增加边界约束和悬浮查看。
- 按钮、链接、截图、复选框、操作菜单和已有详情/统计交互保持原语义。

### 4. 样式和布局约束

- 所有相关表格继续使用 `table-layout: fixed` 和固定列宽。
- 长 URL、域名、CNAME、证书、响应头和指纹只显示紧凑预览。
- 悬浮面板使用 Portal，不受表格、分页容器或虚拟滚动容器的 `overflow-hidden` 影响。
- 面板支持视口右侧/底部边界计算，小屏幕限制最大宽度并允许完整内容滚动。

## Test Plan

- 验证横向截断、多行高度截断、子元素 `truncate`/`overflow-hidden` 的实际检测。
- 验证完整短文本不打开无意义面板，`forceHover`、键盘 Tab、Esc、失焦和复制完整原文行为。
- 验证居中列、数字列、IP、端口、CNAME、站点标题、URL、SSL 证书、目录扫描、WIH、WAF、Nuclei、风险和服务文本。
- 验证 `DataTable` 默认单元格、自定义 AI 日志单元格、固定列宽及相邻列不被挤压。
- 验证虚拟滚动中面板打开、滚动、卸载和重新挂载行为，以及按钮、链接、截图和行操作不被破坏。
- 执行前端单元测试、TypeScript 检查和生产构建。

## Acceptance Criteria

- 截断的 OpenWrt 标题、Microsoft 产品标题、域名和 CNAME 均可悬浮查看完整原文。
- 任意扫描结果文本只要视觉上被截断或隐藏，就能通过鼠标或键盘查看完整内容。
- 任意表格列不会因长文本挤压其它列，且不依赖字符长度阈值判断是否显示悬浮。
- 不新增后端字段，不改变分页、排序、筛选和已有详情弹窗语义。

## Assumptions

- 本专项只处理前端展示，不修改扫描数据内容。
- 操作按钮、表单输入和纯控制状态不强制显示悬浮；带扫描信息的按钮/状态文本保留原点击语义并增加必要的文本查看能力。
- 真实浏览器布局、虚拟滚动和生产构建需在代码实现后继续验收。
