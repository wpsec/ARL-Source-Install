# ARTEX 风格 UI 视觉深化计划

状态：**已归档**。在已完成的 ARTEX 体验对齐基础上，收敛了 ARL 前端视觉细节与信息密度，并完成人工视觉走查。

## 目标与范围

延续已归档的 [`ARTEX 风格 UI 体验对齐计划`](../history/[已归档]ARTEX风格UI体验对齐计划.md)：以浅色中性表面、克制强调色、清晰层级和一致的页面节奏为参考，进一步靠近 ARTEX 的界面观感。保留 ARL 品牌标识、业务功能、五种主题、API、路由和扫描语义，不复制 ARTEX 的品牌资产或代码。

本轮聚焦视觉呈现，不调整后端、扫描流程、权限或数据定义。

## 当前基线与差距

- 砂岩白已经是浅色默认主题，页面、卡片、表格和导航已有统一 token 与组件基线。
- 侧栏分组曾使用不同语义色，选中行的底色和描边较醒目；顶栏系统监控摘要在宽屏上占据较多横向空间。
- 仪表盘和列表页面的卡片边框、阴影、圆角和操作区密度仍可继续收敛，减少装饰竞争，让数据层级更突出。
- 历史多视口截图位于 `/tmp/arl-ui-playwright-results`；本轮实现前应以当前工作区代码为准，截图仅作旧版对照。

- 不变更 API、任务状态语义、扫描步骤、权限行为和现有主题持久化方式。
- 砂岩白继续作为默认主题；ARL 品牌色保留在主要动作及必要的状态强调中。
