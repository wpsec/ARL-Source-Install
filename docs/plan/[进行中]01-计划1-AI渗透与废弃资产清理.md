# 01 计划1：AI 渗透与废弃资产清理

## 目标

彻底移除已放弃的 AI 渗透测试能力及其仓库残留，保留当前仍在使用的 `nuclei / afrog / NPoC / WIH` 主链路。

本阶段必须先于 Rust 热点抽取。Rust 模块不得引用已删除的 AI 渗透模块、配置、数据结构或历史结果字段。

## 删除范围

### 目录与资产

- 删除 `tools/ai_pen_tools`
- 删除 `tools/poc`
- 删除仅服务旧 AI 渗透的知识索引和生成物
- 删除旧 AI 渗透专属 SOP 和 skills

### 后端实现

- 删除 `/ai_pen_test` 全部路由与统计、重试、批量运行、删除逻辑
- 删除 `ai_pen_mcp_runtime`
- 删除 `build_ai_pen_knowledge_index.py`
- 删除 `commonTask` 中 AI 渗透专属执行、候选构建、外部工具调用、知识索引装载逻辑
- 删除任务、导出、统计、控制台等链路中的 `ai_pen_test_result` 读写与展示逻辑

### 配置与前端

- 删除 `config-docker.yaml` 中全部 `AI_PEN_*` 开关和路径
- 删除配置中心中所有 AI 渗透执行相关字段、接口和前端表单
- 删除前端 `AI渗透测试` 模块、统计面板、详情弹窗、批量操作和测试按钮

### 测试与文档

- 删除 `test_ai_pen_*`
- 删除仅验证旧 AI 渗透耦合逻辑的测试
- 删除 README 中 AI 渗透、外部工具目录、PoC 知识库说明
- 将旧 `Strix-cn` 方案改为归档说明

## 明确不做

- 不保留旧 `/ai_pen_test` 只读兼容
- 不保留旧历史查询接口
- 不保留旧 AI 渗透导出与报告章节
- 不为删除能力增加新的兼容层

## Rust 相关边界

- 不为旧 AI 渗透链路新增 Rust adapter、FFI 接口或替代执行器。
- 不把待删除的 AI 渗透逻辑作为 Rust 性能基准样本。
- 删除完成后，Rust crate、Python adapter、构建脚本和配置模板都必须通过同一套残留检索。

## 性能治理前置约束

- AI 渗透废弃链路清理必须先于 Rust 热点抽取和 adapter 接口冻结。
- 清理范围覆盖 Python、Rust、Docker、构建脚本、配置模板和测试；`rg 'ai_pen|AI_PEN'` 必须覆盖全仓，而不是只检查 Python。
- provider 异常、任务错误和阶段指标不得输出 API key、邮箱、Token、密码或带凭据的请求 URL；错误文本进入日志、Mongo 任务详情和 traceback 前必须脱敏。
- 清理完成前不得让 Rust 模块引用已删除的 AI 渗透模块、配置或结果结构，也不得把废弃链路纳入性能样本。
- AI 清理验收通过后，才允许冻结 Rust adapter 的输入、输出、fallback 和 metrics 语义。

## 与统一发现上下文的关系

- AI 废弃链路清理必须先于 `DiscoveryContext`、候选事件和 Rust 解析接口冻结，避免旧 AI 渗透字段进入共享候选图。
- 清理范围覆盖 Python、Rust、Docker、构建脚本、配置模板和测试；共享发现上下文不得引用已删除的 `ai_pen` 模块、状态或结果字段。
- provider、爬虫、WIH、目录扫描的异常日志必须沿用脱敏规则，不得因为统一事件记录而输出 API key、Token、邮箱、密码或带凭据 URL。
- `AI_POC`、AI 去噪和现行 WIH 辅助能力仍需与已删除的 AI 渗透执行链区分，不能把它们作为共享发现策略重新引入旧 runtime。（2026-09-04 修订：`AI_POC` 经用户决策已整体移除，本句仅对 AI 去噪与 WIH 接口辅助继续有效。）

- `build_poc_index.py` 与 `AI_POC` 当前仍存在生产引用，若仍服务保留能力，则不纳入本阶段删除清单。（2026-09-04 修订：保留决策反转，`ai_poc_planner_service.py`、`build_poc_index.py`、`poc_index.json` 及 `AI_POC_SCAN_ENABLE` 配置已删除；同时僵尸化的 `penetration_scan.py`/`penetration_request_policy.py` 与 `strip_disabled_penetration_options` 强制关闭机制一并下线。）
- `nuclei_result`、`vuln` 中保留的 `ai_pen_*` 字段若仅用于旧渗透结论回填，需一并评估是否删除或清空展示。
