# 文档目录

## 目录约定

- `plan/`：当前执行计划和专项实施计划。
- `review/`：代码、架构、兼容性和验收 review 计划与报告。
- `history/`：已经归档、不再作为当前实施依据的历史方案。
- `completed/`：已经完成并闭环、无需继续作为当前执行依据的独立文档。
- `future/`：尚未纳入当前主线、待后续评审的计划。
- `reference/`：开发规范和其它长期参考资料。

## 状态标签

- `[已完成]`：本文档对应的工作范围和验收项已经闭环。
- `[进行中]`：正在实施，仍有后续批次或验收项。
- `[未完成]`：已规划但尚未完成，或仅完成方案分析。
- `[已暂停]`：已有部分实现，但按当前决策暂不继续推进。
- `[已归档]`：历史方案，不再作为现行实施依据。
- `[未来计划]`：尚未进入当前主线。
- `[长期参考]`：目录、规范等长期维护资料，不代表某个实施批次状态。

状态只描述当前文档或其对应工作范围，不等同于整个重构计划的发布验收结论。

## 当前主线

当前重构以 `plan/[进行中]00` 至 `plan/[未完成]07` 为主计划，WIH 调度专项位于 `plan/[进行中]WIH提速与调度优化实施计划.md`。

文档归类只改变路径，不改变计划内容、代码接口或验收语义。移动文档后，新增引用应使用对应目录下的相对路径。

冻结清单由脚本按固定路径生成，已闭环版本统一放在 `completed/` 作为可再生基线；移动前必须同步更新脚本输出路径和全部文档引用。主计划只有全部批次和验收闭环后才移动到 `completed/`。

`review/` 保留评审报告的审计轨迹，即使某一轮 Review 已完成也不自动移出；`history/` 保留被废弃或替换的历史方案。
