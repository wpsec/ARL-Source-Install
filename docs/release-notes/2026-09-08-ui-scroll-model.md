# 2026-09-08 UI 滚动模型与 DataTable

## 行为变更

模块主列表统一由页面主区域承担纵向滚动。首行冻结和表格卡片独立纵向滚动不再提供；这是滚动模型收敛的一部分，不是浏览器兼容性故障。

超宽表格仍支持横向滚动，超过 200 行由 `DataTable` 使用受控虚拟滚动。分页、筛选、排序、勾选、导出、详情和行操作保持原有语义。

## 兼容处理

- 既有 API、字段、分页参数、筛选参数、排序参数和 URL 状态保持兼容。
- 历史缓存、书签和查询参数中若存在冻结相关状态，页面忽略该状态并继续正常加载，不影响数据请求。
- 旧页面遗留的 `sticky`/freeze 样式不再参与主列表布局；新增页面不得依赖表格内部纵向滚动实现冻结首行。
- 弹窗、日志/报文、代码块和下拉层仍按滚动白名单保留受控内部滚动。

## 回归清单

- 模块主列表只产生页面主区域纵向滚动。
- 横向超宽表格仍可拖动/触控滚动。
- 空态、加载态、服务端分页和超过 200 行的虚拟滚动均可渲染。
- 选择框、列排序、批量操作和行操作不因 DataTable 接入丢失。
